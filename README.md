# GameBuild

Aplicativo Android para visualizar e comparar builds de personagens de múltiplos jogos.

## Jogos iniciais

- Neverness to Everness (NTE)
- Warframe
- Arknights: Endfield

## V0.1

A primeira versão valida a fundação do aplicativo: seleção do jogo, seleção de personagem, tela inicial de build, tratamento básico de erros e pipeline de CI.

Os dados da V0.1 são placeholders. Builds reais, imagens e fontes externas entram nas próximas versões.

## Tecnologia

Kotlin, Jetpack Compose, Material 3, ViewModel/StateFlow, Repository Pattern e GitHub Actions.

## Desenvolvimento

Abra a pasta no Android Studio para configurar SDK/AVD ou no VS Code para editar o código. O emulador recomendado é um dispositivo API 35.
