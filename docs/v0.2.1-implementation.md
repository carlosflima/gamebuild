# V0.2.1 — NTE UI implementation

Implemented in this branch:
- Search characters by name.
- Filter by element and role.
- Clear active filters.
- Character count and empty-state handling.
- Safe visual placeholder for character artwork.
- Build screen back navigation.
- Version bumped to 0.2.1 at the application metadata level.

Images remain optional: the domain already stores `imageUrl`, but the UI does not fail when an image is unavailable. A dedicated image-loading dependency will be evaluated in a later change after dependency/CI validation.
