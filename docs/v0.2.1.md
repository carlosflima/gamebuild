# V0.2.1 — NTE character experience

## Scope
- Character search by name.
- Filters by element and role.
- Character cards with optional remote image and safe placeholder fallback.
- Build screen with provenance and structured recommendations.
- No image is treated as mandatory for the app to function.

## Data policy
Remote character images are optional and are referenced through `imageUrl`. The app must continue to work when an image cannot be downloaded.
